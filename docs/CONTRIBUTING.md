# Team Contribution Workflow

1. Create or select a GitHub issue describing one task and its acceptance criteria.
2. Create a focused branch, for example `feature/student-profile` or `test/eligibility-rules`.
3. Make small, logically grouped commits using messages such as `feat: add profile validation`, `test: cover eligibility boundaries`, or `docs: update test results`.
4. Run relevant tests before opening a pull request.
5. Ask a teammate to review the change and link the issue.
6. Merge only after review and required checks; update documentation and test evidence.

Never commit database passwords, personal student data, generated build output, or local IDE settings.
