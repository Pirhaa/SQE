## Severity guide
- **Critical:** data loss, security breach, or application unusable.
- **High:** major required workflow fails with no reasonable workaround.
- **Medium:** feature partially fails or has a workaround.
- **Low:** minor usability or cosmetic issue.

Suggested status values: New, Assigned, In Progress, Fixed, Retest, Closed, Reopened.
